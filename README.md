# Lucas Zanotto — Portfólio

Site pessoal de apresentação dos meus serviços como desenvolvedor full stack.

**🔗 Online:** [portfolio-eta-seven-k26bbsdrld.vercel.app](https://portfolio-eta-seven-k26bbsdrld.vercel.app)

## Destaques

- Layout responsivo (mobile first), sem frameworks e sem dependências
- Bilíngue (PT / EN), com detecção automática do idioma do navegador
- Formulário de contato que envia a mensagem formatada direto para o WhatsApp
- Projetos renderizados a partir de uma lista em `main.js`, fácil de manter
- Animações leves com `IntersectionObserver` e suporte a `prefers-reduced-motion`

## Tecnologias

HTML5 · CSS3 · JavaScript (ES2022)

## Rodando localmente

```bash
npx http-server . -p 5173
```

## Adicionando um projeto

Edite o array `PROJECTS` no início de `main.js`. Cada item recebe nome, descrição (PT/EN), stack, imagem e os links de demo e repositório.
